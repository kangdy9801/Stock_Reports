# 공시 읽기 노트

DART에서 내려받은 반기·분기·사업보고서 PDF를 올리면, 투자 전에 확인할 9단계 체크리스트로 숫자를 정리해 주는 개인용 웹사이트입니다. 탭이 세 개입니다.

| 탭 | 넣는 파일 | 비교 방식 |
| --- | --- | --- |
| **반기보고서 비교** | 반기보고서만, 최대 3개 (예: 2024·2025·2026년 반기) | 같은 상반기끼리 연도별 비교. 1개만 넣으면 보고서 안의 전년 동기 숫자와 비교 |
| **분기보고서 분석** | 분기보고서(1분기·3분기)만, 최대 3개 | 손익은 각 분기 3개월 숫자, 현금흐름은 누적 숫자. 최신 분기와 1년 전 같은 분기 보고서가 없으면 보고서 안의 전년 같은 분기 숫자로 비교 열을 만듦 |
| **사업보고서 분석** | 사업보고서(정정본 포함)만, 최대 3개 | 보고서 1개에 들어 있는 3개 연도를 펼쳐 연도별 비교. 2개면 4년, 3개면 최대 5년 |

다른 종류의 보고서(분기보고서, 다른 탭의 보고서)를 넣으면 이유를 알려 주고 받지 않습니다.

- 9단계 판정표, 매출에서 FCF까지 이어지는 그래프, 단계별 숫자 표를 만듭니다.
- **함께 알아두면 좋은 점**: 순이익과 영업이익의 차이, 재고·매출채권 급증, 지분 희석, 전환사채, 단기 유동성 같은 점을 숫자와 함께 짚어 줍니다.
- **투자 전 확인사항**: 공통 항목과, 이 회사 숫자에서 나온 항목을 체크리스트로 보여 주고 체크 상태와 메모를 저장합니다.
- **9단계 주가**: 주가는 직접 입력합니다. 발행주식수, 12개월 실적, 이익 성장률, 순현금, 비지배지분 등 모든 칸을 고칠 수 있고 **PER, PEG, PBR, PSR, EV/EBITDA**, FCF 수익률, EV/영업이익이 바로 다시 계산됩니다.
- **기록 저장**: 결과를 브라우저에 저장하고 다시 열 수 있습니다. 파일(.json)로 내보내 백업하거나 다른 컴퓨터에서 불러올 수 있습니다.
- **인쇄·PDF 저장**: 인쇄용 레이아웃으로 정리되어, 브라우저 인쇄 창에서 PDF로 저장할 수 있습니다.

PDF는 내 브라우저 안에서만 읽습니다. 서버로 보내지 않으며, 저장 기록에도 PDF 원본은 들어가지 않습니다(추출한 숫자와 원문 한 줄만 저장).

## GitHub Pages로 올리기

### 방법 A. 웹 화면에서 (git 설치 없이)

1. GitHub에 로그인하고 오른쪽 위 **+ → New repository**를 누릅니다.
2. 저장소 이름(예: `gongsi-note`)을 정하고 **Public**으로 만듭니다. (무료 계정에서 Pages를 쓰려면 Public이어야 합니다.)
3. 만들어진 저장소에서 **Add file → Upload files**를 누르고, 이 폴더 안의 파일과 폴더를 **전부** 끌어다 놓습니다. `index.html`이 저장소 맨 위에 있어야 합니다. 숨김 파일 `.nojekyll`도 함께 올려 주세요.
4. **Commit changes**를 누릅니다.
5. 저장소의 **Settings → Pages**로 갑니다. **Build and deployment**의 Source를 **Deploy from a branch**, Branch를 **main**, 폴더를 **/(root)**로 고르고 **Save**를 누릅니다.
6. 1~2분 뒤 같은 화면 위쪽에 `https://아이디.github.io/gongsi-note/` 주소가 나타납니다. 이 주소가 내 사이트입니다.

### 방법 B. 명령줄에서

```bash
cd gongsi-note
git init
git add .
git commit -m "공시 읽기 노트 첫 버전"
git branch -M main
git remote add origin https://github.com/아이디/gongsi-note.git
git push -u origin main
```

그다음 방법 A의 5~6단계(Settings → Pages)를 똑같이 하면 됩니다.

### 내 컴퓨터에서 먼저 써 보기

`index.html`을 더블클릭하면 PDF 읽기 도구가 막혀 동작하지 않습니다. 폴더에서 아래처럼 간단한 서버를 켠 뒤 `http://localhost:8000`을 여세요.

```bash
python3 -m http.server 8000
```

## 쓰는 법

1. DART(dart.fss.or.kr)에서 회사를 검색해 반기보고서나 사업보고서를 열고, 오른쪽 위 **다운로드**에서 PDF를 받습니다.
2. 위쪽 탭에서 **반기보고서 비교**, **분기보고서 분석**, **사업보고서 분석** 중 하나를 고르고 PDF를 끌어다 놓습니다(탭마다 최대 3개). 두 탭은 서로 따로 작업되고, 기록도 탭별로 저장됩니다.
3. 판정표와 단계별 숫자를 읽고, 맨 아래 **추출값 확인·수정**에서 자동으로 찾은 숫자가 원문과 맞는지 확인합니다. 칸을 고치면 모든 계산에 반영되고, 비우면 자동값으로 돌아갑니다.
4. 9단계에 주가와 기준일을 직접 넣습니다. 종목코드를 넣으면 네이버 증권 일별 시세 링크가 생겨 확인하기 편합니다.
5. **기록 저장**, **인쇄·PDF 저장**, **파일로 내보내기**로 결과를 남깁니다.

## 숫자를 찾는 방식과 한계

- 재무상태표, 포괄손익계산서, 현금흐름표, 요약재무정보, 발행주식의 총수, 수주상황 표를 찾아 계정 이름으로 숫자를 읽습니다. 연결재무제표가 있으면 연결 기준, 없으면 별도 기준을 씁니다.
- 회사마다 계정 이름이 조금씩 달라 일부 숫자를 못 찾거나 다른 줄을 읽을 수 있습니다. 각 숫자 옆에 원문 줄이 표시되니 꼭 대조하세요.
- 스캔한 이미지 PDF(글자를 선택할 수 없는 PDF)는 읽을 수 없습니다. DART에서 받은 PDF를 그대로 쓰세요.
- 이자보상배율은 현금흐름표의 **이자 지급액**으로 계산합니다(주석의 이자비용과 다를 수 있음).
- **EBITDA** = 영업이익 + 감가상각비·무형자산상각비. 상각비는 주석의 '비용의 성격별 분류'에서, 없으면 '현금흐름표(에 관한 정보)'의 조정 항목에서 찾습니다. 사업보고서의 가장 오래된 연도는 주석에 상각비가 없어 비어 있을 수 있습니다.
- **EV** = 시가총액 − 순현금(현금성 자산 − 이자 붙는 빚) + 비지배지분.
- **PEG** = PER ÷ 이익 성장률(%). 기본 성장률은 과거 숫자로 계산한 여러 값(연평균 성장률, 전년 대비, 전년 동기 대비, 12개월 이익의 직전 연도 대비) 중 **보수적으로 가장 낮은 값**입니다. 앞으로의 기대 성장률로 바꿔 넣는 것을 권합니다.
- 분기 탭의 EBITDA는 상각비가 누적 숫자라 **누적 기준**입니다. 이자보상배율도 누적 영업이익으로 계산합니다.
- 반기·분기 탭의 12개월 실적은 `직전 사업연도 − 전년 같은 기간 누적 + 올해 누적`(요약재무정보 사용)입니다. 반기 탭의 12개월 FCF와 상각비는 누적값을 단순 연환산한 **추정치**입니다.
- 판정(개선·양호·주의 등)은 정해진 규칙에 따른 참고용 표시입니다. 투자 판단은 본인의 몫입니다.

## 기록은 어디에 저장되나요

- **기록 저장**은 이 브라우저의 저장소(localStorage)에 남습니다. 브라우저 데이터를 지우거나 다른 브라우저·컴퓨터를 쓰면 보이지 않습니다.
- 오래 보관할 기록은 **파일로 내보내기**로 `.json` 파일을 받아 두고, 필요할 때 **파일 불러오기**로 여세요.
- 저장 기록에는 작업 기록(파일 추가, 값 수정, 저장 시각)이 함께 남습니다.

## 폴더 구조

```
index.html            화면
css/style.css         디자인(인쇄용 레이아웃 포함)
js/extract.js         PDF → 줄 단위 텍스트
js/parser.js          보고서에서 숫자 찾기
js/analysis.js        9단계 지표, 판정, 알아두면 좋은 점, 확인사항, 주가 계산
js/storage.js         기록 저장소
js/app.js             화면 동작
vendor/pdfjs/         PDF 읽기 라이브러리(pdf.js 3.11.174, Apache-2.0)
CHANGELOG.md          변경 기록
```
